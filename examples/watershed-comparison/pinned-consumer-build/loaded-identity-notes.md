# Installed native identity probe

The probe imports the exact installed wheel and calls `_self_test_proj()` before enumeration. `ctypes.CDLL(None)` exposes `_dyld_image_count` and `_dyld_get_image_name` on macOS. Normalize each loader path and each receipt key with `Path.resolve()`, then match by full resolved absolute path. Compare SHA256 of that file against the receipt. Do not match by basename: different versions or prefixes can share a name. Homebrew `opt` symlinks and `Cellar` paths identify the same file only after resolution. An upgrade that changes the symlink must fail the check.

Result: 495 loader images; every one of the receipt's 53 native libraries is loaded and its current on-disk hash matches. Native image names can include `@rpath` in Mach-O dependency commands; use resolved dyld loaded image names instead of parsing `otool -L` as proof of loading. Apple shared-cache images can have paths without standalone files. Record those separately; this receipt intentionally hashes Homebrew native dependencies only. Enumeration should occur after required native initialization, without concurrent library-loading threads. A dynamic plugin loaded only later cannot be attested by this initial snapshot. Repeat after the operation if that boundary matters.

This checks the bytes at loaded image paths, not relocated executable memory. It assumes files are not replaced concurrently after dyld maps them. Hashing mapped memory is not equivalent to a wheel/dylib hash due to relocation and code signing. Receipts must state this filesystem-race limit rather than claiming memory attestation.

Wheel verification reads the exact zip archive and compares every installed member byte-for-byte through `importlib.metadata.distribution('pourpoint').locate_file`, including facade, stubs, extension, license and metadata files. Skip only `.dist-info/RECORD`, which installers rewrite. `direct_url.json`, `INSTALLER`, REQUESTED and pycache can be generated by installers. For package content, reject extra unowned files except pycache, or run Python with bytecode disabled and clear prior pycache to avoid stale-bytecode ambiguity. Native `_data` contents, if present in a wheel, must be included in member verification. This native wheel has no bundled `_data`; GDAL/PROJ use system data, whose hashes are not in the existing native-library receipt. `_self_test_proj()` proves current functionality, not data identity.

Result: all 23 checked wheel members match and no unexpected package files exist. Verify imported package and extension paths also resolve under that distribution package directory. Reject editable `direct_url.json` dir_info.editable and check wheel archive SHA256 against receipt before reading members. This probe reads the known finalized receipt and focuses on native mapping and member verification; production acceptance must also enforce those receipt/archive/import checks.

Evidence: `probe-loaded-identity.py` and `loaded-identity-probe.json` next to this note. Finalized receipt was not modified.
