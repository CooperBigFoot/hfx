# HFX

HFX, HydroFabric Exchange, is an open specification and Rust toolkit for a compiled drainage format.
A source hydrofabric, a dataset describing a region's river network, compiles into HFX offline.
A delineation engine then reads HFX through one normalized contract.

This site renders the HFX specification.
Open the Specification section to read the normative spec, the auxiliary schemas, and the changelog.
