# Upstream Tech Public Hydrologic Basin Delineation Datasets

This bucket hosts exactly one dataset: the GRIT 2.0.0 HFX dataset, an HFX
v0.2.1 compilation of the Global River Topology (GRIT) vector datasets,
stored under `grit/2.0.0/`.

- [README.md](https://basin-delineations-public.upstream.tech/grit/2.0.0/README.md)
- [NOTICE](https://basin-delineations-public.upstream.tech/grit/2.0.0/NOTICE)
- [CITATION.txt](https://basin-delineations-public.upstream.tech/grit/2.0.0/CITATION.txt)
